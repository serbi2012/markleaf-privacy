MarkLeaf 개인정보처리방침

시행일 2026년 10월 15일 · 대상: 크롬 확장 프로그램 MarkLeaf

MarkLeaf 는 사용자의 문서 내용과 개인정보를 어디에도 전송하지 않습니다. 개발자는 서버를 운영하지 않으며, 분석·광고·추적 코드를 넣지 않습니다.

1. 수집하는 정보

없습니다. MarkLeaf 는 이름, 이메일, 사용 기록, 문서 내용 등 어떤 정보도 개발자나 제3자에게 보내지 않습니다.

2. 사용자 기기 안에만 저장하는 정보

기능을 위해 아래 정보를 사용자의 브라우저 안에만 저장합니다. 이 정보는 개발자가 볼 수 없습니다.

정보저장 위치용도
보기 설정(테마, 글자 크기 등)크롬 저장소(크롬 동기화를 켰다면 사용자의 구글 계정으로 동기화)모든 문서에 같은 설정 적용
커스텀 CSS크롬 로컬 저장소사용자가 입력한 스타일 적용
파일·폴더 접근 권한(핸들), 최근 문서 목록브라우저 IndexedDB사용자가 고른 파일에 다시 저장
저장하지 않은 초안, 버전 기록(문서별 최근 30개)브라우저 IndexedDB실수로 닫았을 때 복구, 예전 내용으로 되돌리기
문서별 읽던 위치브라우저 로컬 저장소다시 열면 읽던 곳으로 이동

확장 프로그램을 삭제하거나 브라우저의 사이트 데이터를 지우면 함께 삭제됩니다.

3. 권한을 쓰는 이유

로컬 파일(file://)과 GitHub Raw 주소의 .md 문서를 표시하고, 사용자가 허용한 사이트의 .md 원문만 문서로 바꾸기 위해 필요한 권한만 사용합니다. 파일에 저장하는 것은 사용자가 크롬의 파일·폴더 선택 창에서 직접 고른 파일과 폴더뿐입니다.

4. 외부 리소스

모든 글꼴과 라이브러리(Milkdown, KaTeX, Mermaid, highlight.js 등)는 확장 프로그램 안에 들어 있어 외부 서버에서 내려받지 않습니다. 문서 안의 이미지·링크처럼 문서 작성자가 넣은 외부 주소는 일반 웹페이지와 같이 브라우저가 불러옵니다.

5. 변경과 문의

이 방침이 바뀌면 이 페이지와 시행일을 갱신합니다. 문의는 크롬 웹 스토어의 MarkLeaf 페이지에 있는 개발자 연락처로 보내 주세요.
