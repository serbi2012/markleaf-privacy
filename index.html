MarkLeaf 개인정보처리방침

시행일 2026년 10월 20일 (처음 2026년 10월 15일) · 대상: 크롬 확장 프로그램 MarkLeaf

MarkLeaf 는 사용자의 문서 내용과 개인정보를 어디에도 전송하지 않습니다. 개발자는 서버를 운영하지 않으며, 분석·광고·추적 코드를 넣지 않습니다.

1. 수집하는 정보

없습니다. MarkLeaf 는 이름, 이메일, 사용 기록, 문서 내용 등 어떤 정보도 개발자나 제3자에게 보내지 않습니다.

2. 사용자 기기 안에만 저장하는 정보

기능을 위해 아래 정보를 사용자의 브라우저 안에만 저장합니다. 이 정보는 개발자가 볼 수 없습니다.

3. 문제 신고

옵션이나 팝업의 [문제 신고]를 누르면 버전·브라우저·설정·최근 오류 기록을 클립보드에 복사만 합니다. MarkLeaf 가 자동으로 보내지 않으며, 사용자가 직접 붙여 넣어 보낼 때에만 그 내용이 전달됩니다. 문서 내용과 파일 경로는 들어 있지 않습니다.

4. 맞춤법 검사

맞춤법 검사는 기본으로 꺼져 있습니다. 켜면 브라우저에 들어 있는 맞춤법 검사 기능을 그대로 씁니다. MarkLeaf 는 글을 보내지 않지만, 크롬 설정에서 ‘향상된 맞춤법 검사’를 켜 두었다면 크롬이 입력한 글을 구글의 맞춤법 서비스로 보낼 수 있습니다. 이 동작은 크롬 설정을 따릅니다.

5. 권한을 쓰는 이유

로컬 파일(file://)과 GitHub Raw 주소의 .md 문서를 표시하고, 사용자가 허용한 사이트의 .md 원문만 문서로 바꾸기 위해 필요한 권한만 사용합니다. 파일에 저장하는 것은 사용자가 크롬의 파일·폴더 선택 창에서 직접 고른 파일과 폴더뿐입니다.

6. 외부 리소스

모든 글꼴과 라이브러리(Milkdown, KaTeX, Mermaid, highlight.js 등)는 확장 프로그램 안에 들어 있어 외부 서버에서 내려받지 않습니다. 문서 안의 이미지·링크처럼 문서 작성자가 넣은 외부 주소는 일반 웹페이지와 같이 브라우저가 불러옵니다.

7. 변경과 문의

이 방침이 바뀌면 이 페이지와 시행일을 갱신합니다. 문의는 크롬 웹 스토어의 MarkLeaf 페이지에 있는 개발자 연락처나 지원 탭으로 보내 주세요.

MarkLeaf Privacy Policy

Effective October 20, 2026 (first published October 15, 2026) · Applies to the MarkLeaf Chrome extension

MarkLeaf never sends your documents or personal information anywhere. The developer runs no servers and includes no analytics, advertising or tracking code.

1. Information we collect

None. MarkLeaf does not send your name, email, usage history, document text or any other information to the developer or to third parties.

2. Information stored only on your device

To make its features work, MarkLeaf stores the following only inside your browser. The developer cannot see it.

All of it is deleted when you remove the extension or clear the browser's site data.

3. Reporting a problem

[Report a problem] in the options page or popup only copies the version, browser, settings and recent error log to your clipboard. MarkLeaf never sends it; it reaches anyone only if you paste and send it yourself. It contains no document text or file paths.

4. Spell check

Spell check is off by default. When you turn it on, MarkLeaf uses your browser's built-in spell checker. MarkLeaf does not send your text, but if “Enhanced spell check” is on in Chrome's settings, Chrome may send what you type to Google's spelling service. That behavior follows your Chrome settings.

5. Why we need permissions

MarkLeaf uses only the permissions needed to show local (file://) and GitHub Raw .md files as documents, and to turn .md source pages into documents only on sites you allow. It saves only to files and folders you pick yourself in Chrome's file and folder pickers.

6. External resources

All fonts and libraries (Milkdown, KaTeX, Mermaid, highlight.js and others) are bundled in the extension and are never downloaded from external servers. External addresses that a document's author put in the document, such as images and links, are loaded by the browser like on any web page.

7. Changes and contact

If this policy changes, this page and its effective date will be updated. For questions, use the developer contact or the support tab on MarkLeaf's Chrome Web Store page.
